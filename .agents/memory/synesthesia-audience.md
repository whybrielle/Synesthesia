name: Synesthesia audience
description: Accessibility and tone requirements for older adults and healthcare aides.
---

Synesthesia should be approachable for older adults and healthcare aides supporting a shared creative activity.

**Why:** The user named these groups as audiences who need the interface to be easier to use.

**How to apply:** Favor readable text, strong contrast, large touch controls, plain language, predictable steps, and a respectful, non-infantilizing tone. Keep the local-only privacy message clear.
